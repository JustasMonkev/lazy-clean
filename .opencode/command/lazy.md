Switch to lazy $ARGUMENTS mode. If the arguments begin with `default`, `/lazy default <level>` records what LATER sessions start at: do not switch on your own, and report exactly what the lazy hook reported — it logs whether the default was stored, was rejected as an invalid level, or could not be written, and on OpenCode it also says when this chat holds no level of its own and so follows the new default from the next message. Take that from the hook rather than assuming either way, and never state that a default was saved unless the hook said so. With no level given, report the level already active — the one named in your context, or off if none is — and switch nothing.
